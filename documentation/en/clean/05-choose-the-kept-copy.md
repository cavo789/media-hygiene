# 5. Choose which copy stays

[Documentation](../README.md) › Cleaning, step 5 of 14 · 🇫🇷 [Français](../../fr/clean/05-choose-the-kept-copy.md)

Between identical copies, the tool keeps one and marks the others as extra. Its choice is
sensible, but you know your folders better. Three options let you steer it, one at a time.

## How the tool chooses

For each group of identical files, the first rule that makes a difference decides:

1. a **protected** folder (see below);
2. a **preferred** folder, in the order you gave them;
3. the copy that has a [sidecar](../reference-sidecars.md) (`.xmp`, `.aae`, `.thm`): it keeps its edits;
4. a name that does not look like a copy: `IMG_0101.jpg` rather than `IMG_0101 (1).jpg` or `IMG_0101 - Copy.jpg`;
5. a name someone chose rather than one generated by a camera or an app: `Marie et Paul.jpg` rather than `IMG_1234.jpg` or a bare number such as `162.mp4`;
6. a folder someone named rather than a generic one or one that only says a date: `Holidays 2019` or `Saint-Cyprien` rather than `DCIM\100CANON` or `July 2018`;
7. the oldest date, then the shortest path, then alphabetical order.

The same folders always give the same choice. The report says, for each pair and each group,
which rule decided (*why: the oldest date*).

The kept file keeps its name and its folder; the name of a copy set aside is lost once purged.
So look at the folder pairs of the audit: is the kept folder the one you want?

## Prefer a folder

In the demo library, `C:\Photos\2019\Seaside holidays` is kept rather than `C:\Photos\Old phone`
(its dates are older). To keep the copies of `Old phone` instead, name it with `--prefer`, after
`audit`:

```powershell
mh audit --prefer "C:\Photos\Old phone"
```

## Protect a folder

`--protect` goes further: the folder is **never modified**, and its files are always the copies
kept. Think of a master library:

```powershell
mh audit --protect "C:\Photos\Family"
```

(the `docker run … -v …` part stays the same; only the end of the command changes)

Be aware of what it means: identical files *elsewhere* are set aside, since the protected copy is
the one kept. Broken files and orphan sidecars of a protected folder are left alone too.

## Exclude a folder

`--exclude` removes a folder from the analysis: its files are neither read nor compared. Use it
for a folder the tool must not even read (a backup you want checked is
[compared](#compare-a-backup-or-an-old-disk) instead):

```powershell
mh audit --exclude "D:\Old disk"
```

Only the duplicates of `C:\Photos` remain:

## Compare a backup or an old disk

`--backup` (or `backups` in `[folders]` of `config.toml`) marks a folder as a backup: it is read
and compared by content, **never changed**, and its copies are never the reason a file of your
photos goes. Unlike a protected folder, it does not keep anything: it is only compared.

```powershell
mh folders add --backup "D:\backup"
mh audit
```

`mh folders add --backup` mounts it read-only for every command, `clean` included, and gives it
as `--backup` to `audit`, `review`, `clean` and `crosscheck`
([`launcher`](../commands/launcher.md#change-your-folders-mh-folders)).

Per backup folder, the audit says two things, the report lists them, and two files next to
`plan.csv` list every file (host paths, readable by Excel):

- **Not in the backup** (`backup-missing.csv`): the files of your photos without an identical
  copy in it. Is my backup complete?
- **Only in the backup** (`backup-only.csv`): its files without an identical copy in your photos:
  deleted from your photos since, or, on an old disk, the files to copy before wiping it.

Good to know:

- **Identical means byte for byte** (the same fingerprint): a resized or recompressed copy does not
  count as backed up.
- **`clean`, `review` and `crosscheck`** take `--backup` too: its files are left out of the
  duplicate groups, the near duplicates, the burst series and Czkawka's run. `sort`, `album` and
  `xmp` never write there either.
- **One role per folder**: a backup folder cannot be preferred, protected or excluded too, nor lie
  inside such a folder or hold one. The tool refuses it and names both folders.
- **Time**: the first audit reads a backup like any other folder, its files compared by
  fingerprint when another file has the same size. Count about 465 MB per second (measured on the
  maintainer's PC, first audit of a library); an old USB hard disk is slower. The next audits take
  it from [the cache](../start/02-keep-the-cache.md).
- **Nothing is copied**: the tool says what to copy; you copy.

## Skip a folder name on every disk

Some folders come back everywhere: a camera's `Thumbnails`, Lightroom's `*.lrdata` previews, a
NAS's own recycle bin. Rather than one `--exclude` per path, `--exclude-name` skips a folder **by
its name**, wherever it is:

```powershell
mh audit --exclude-name "Thumbnails,*.lrdata"
```

- The name matches the **whole** folder name, case ignored: `Thumbnails` skips `thumbnails` but
  not `Old Thumbnails`. `*` stands for any characters and `?` for one: `.Trash-*`, `*.lrdata`.
- Repeat it, or separate names with commas (a name holding a comma: write `?` in its place). A
  path (`D:\backup`) is refused: one precise folder is `--exclude`.
- Same meaning as `--exclude`: not analysed, so neither deleted nor used as the kept copy. The
  audit names the folder names it skips.

These names add to the folders always skipped, because they never hold your photos: the Windows
recycle bin (`$RECYCLE.BIN`, `System Volume Information`), Synology (`@eaDir`, `#recycle`), QNAP
(`@Recycle`, `.@__thumb`), the Linux and macOS trash bins of external disks (`.Trash`,
`.Trash-1000`, `.Trashes`), thumbnail caches (`.thumbnails`) and the tool's own folder
(`media-hygiene`: quarantine, reports, cache). A trash is not only noise: if
its copy were the one kept, emptying the trash would lose the photo. `media-hygiene config` lists
them.

## Options come after the command

`--prefer`, `--protect`, `--exclude` and `--exclude-name` go **after** `audit` (and later after
`clean` or `review`). `--locale` is different: it concerns the whole tool, so it goes **before**
the command: `cavo789/media-hygiene --locale fr audit --prefer "C:\Photos\Old phone"`.

Typing the same options every time? [Step 7](07-configuration-file.md) writes them once in a
file.
