# 5. Choose which copy stays

[Documentation](README.md) › Step 5 of 13 · 🇫🇷 [Français](../fr/05-choose-the-kept-copy.md)

Between identical copies, the tool keeps one and marks the others as extra. Its choice is
sensible, but you know your folders better. Three options let you steer it, one at a time.

## How the tool chooses

For each group of identical files, the first rule that makes a difference decides:

1. a **protected** folder (see below);
2. a **preferred** folder, in the order you gave them;
3. the copy that has a [sidecar](reference-sidecars.md) (`.xmp`, `.aae`, `.thm`): it keeps its edits;
4. a name that does not look like a copy: `IMG_0101.jpg` rather than `IMG_0101 (1).jpg` or `IMG_0101 - Copy.jpg`;
5. a name someone chose rather than one generated by a camera or an app: `Marie et Paul.jpg` rather than `IMG_1234.jpg`;
6. a folder someone named rather than a generic one: `Holidays 2019` rather than `DCIM\100CANON`;
7. the oldest date, then the shortest path, then alphabetical order.

The same folders always give the same choice. The report says, for each pair and each group,
which rule decided (*why: the oldest date*).

The kept file keeps its name and its folder; the name of a deleted copy is lost. So look at the
folder pairs of the audit: is the kept folder the one you want?

## Prefer a folder

In the demo library, `C:\Photos\2019\Seaside holidays` is kept rather than `C:\Photos\Old phone`
(its dates are older). To keep the copies of `Old phone` instead, name it with `--prefer`, after
`audit`:

```powershell
docker run --rm -it `
  -v "C:\Photos:/data/c/Photos:ro" `
  -v "D:\Old disk:/data/d/Old disk:ro" `
  -v media-dedup-cache:/cache `
  cavo789/media-dedup audit --prefer "C:\Photos\Old phone"
```

first one wins when a file is in both.

## Protect a folder

`--protect` goes further: the folder is **never modified**, and its files are always the copies
kept. Think of a master library:

```powershell
cavo789/media-dedup audit --protect "C:\Photos\Family"
```

(the `docker run … -v …` part stays the same; only the end of the command changes)

Be aware of what it means: identical files *elsewhere* are deleted, since the protected copy is
the one kept. Broken files and orphan sidecars of a protected folder are left alone too.

## Exclude a folder

`--exclude` removes a folder from the analysis: its files are neither read nor compared. Use it
for a real backup that must stay a second copy:

```powershell
cavo789/media-dedup audit --exclude "D:\Old disk"
```

Only the duplicates of `C:\Photos` remain:

## Options come after the command

`--prefer`, `--protect` and `--exclude` go **after** `audit` (and later after `clean` or
`review`). `--locale` is different: it concerns the whole tool, so it goes **before** the
command: `cavo789/media-dedup --locale fr audit --prefer "C:\Photos\Old phone"`.

Typing the same options every time? [Step 7](07-configuration-file.md) writes them once in a
file.
